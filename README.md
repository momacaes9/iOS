## App Team Carolina iOS Bootcamp

All projects live in this repo, one folder each. Every folder has a `screenshot.png`.

| Project | What it does |
|---|---|
| [SpotifyUI](SpotifyUI) | Spotify-style "Now Playing" screen for *Bohemian Rhapsody* with a working slider, play/pause, shuffle/repeat and add button. |
| [WeatherApp](WeatherApp) | Apple Weather recreation for Chapel Hill with an hourly scroll, a 10-day forecast and temperature range bars. |
| [Reminders](Reminders) | Apple Reminders recreation using `@State` and `@Binding`: add, delete, complete, and edit the list's name and color. |
| [Trivvey](Trivvey) | Trivia app that decodes 547 questions from JSON with `Codable`, with `NavigationStack` and a shuffle button. |

Built with SwiftUI with AI assistance, which was disclosed to the bootcamp leads.
